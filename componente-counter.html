Counter

O Counter é um seletor de quantidade com um botão de diminuir, o valor atual e um botão de aumentar. Use para escolher quantidades, como itens no carrinho ou linhas de um plano; ele pode trocar o botão de diminuir por uma lixeira para remover o item.

Componentes

Resumo

Seletor de quantidade com um botão de diminuir (−), o valor atual e um botão de aumentar (+). Usado para escolher quantidades, como itens no carrinho ou número de linhas de um plano. Pode trocar o botão de diminuir por uma lixeira quando o valor chega ao mínimo, para remover o item.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Counter

  • ⚠️ Limites: informe o valor inicial, o mínimo e o máximo. Sem eles, o código usa mínimo 0 e máximo 999.
  • ⚠️ Lixeira: só aparece quando o valor está no mínimo. Indique no fluxo o que acontece ao clicar nela (ex.: o item sai do carrinho).
  • ⚠️ Fundo: o Counter não tem Theme context no Figma. No código, a borda muda sozinha sobre fundo Brand, Negative ou Media.

ℹ️ Controlado × não controlado: com value, quem controla o valor é você (atualize value no onChangeValue). Sem value, o contador guarda o valor sozinho, começando em defaultValue.

ℹ️ Limites: o valor exibido fica sempre entre min e max. Um value ou defaultValue fora desse intervalo é ajustado para o limite mais próximo.

ℹ️ Leitor de tela: a cada mudança, o valor é anunciado com o nome e os limites, por exemplo "2, linhas, mínimo 1, máximo 5". Os limites só entram no anúncio quando min e max são passados.

ℹ️ O componente não aceita children.

⚠️ O Counter não é um campo de formulário: não tem name e não guarda o valor num Form. Para enviar o valor, guarde-o no estado (modo controlado) e envie junto com os dados do formulário.

Dúvidas reais respondidas pelo suporte

Dúvida: No Counter com Remove e MinValue, dá para deixar a lixeira desabilitada (impedir de excluir o último item)? Resposta: Não. A ação remove aparece quando o contador chega a 1 e serve justamente para remover. Para impedir que o valor caia abaixo do mínimo, use MinValue (sem Remove): o "–" fica desabilitado. Disabled desabilita o componente inteiro. Para outro comportamento, abra uma sugestão de melhoria explicando objetivo e impacto.

Ref. #73 · 12/2024 · ⚠️ limitação atual

Dúvida: O Counter desktop dentro do slot (zona C) de um Boxed Row ficava com padding quebrado e o MinValue não desabilitava o "–". Resposta: O bug do Counter foi corrigido, mas o do slot não pôde ser resolvido sem quebrar o slot. Recomendação: crie um componente local com o Counter e coloque-o manualmente no Boxed Row.

Ref. #105 · 01/2025

Dúvida: O usuário pode clicar no número do Counter e digitar a quantidade? Resposta: Não. O Counter só permite alterar o valor pelos botões – e +.

Ref. #106 · 01/2025

Dúvida: Posso trocar o Counter por um botão "Excluir" (via slot/actions)? Resposta: O Counter já mostra a opção de excluir quando chega a 1. Para um botão de excluir, use o Button Link com StartIcon/EndIcon (havia bug do chevron no Button Link Danger). Trocar o padrão de tela é decisão de Pesquisa e Evolução.
