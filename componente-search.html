Search Field

O Search Field é o campo de busca, com uma lupa à esquerda e um botão para apagar o texto. Use para buscar conteúdos numa página ou lista; ele pode mostrar sugestões enquanto o usuário digita. Tem o mesmo visual do Text Field.

Campos de formulário

Resumo

Campo de busca. Tem um ícone de lupa à esquerda e, quando há texto, um botão ✕ à direita que apaga a busca. Pode mostrar uma lista de sugestões enquanto o usuário digita (getSuggestions), com um texto para quando não há sugestões (withSuggestionsEmptyCase). Tem o mesmo visual do TextField e funciona sozinho ou dentro de um Form.

Regras que não aparecem no Figma (pontos de atenção no handoff)

SearchField

  • ⚠️ Sugestões: diga de onde vêm as sugestões e quando aparecem (ao focar ou depois de quantas letras). No código, cada sugestão é um texto: não desenhe sugestões com ícones ou imagens no Slot.
  • ⚠️ Sem sugestões: se a lista mostra um texto quando não há sugestões, informe o texto em português (o padrão do Figma está em inglês; o do código é "Sem sugestões").
  • ⚠️ Busca num formulário: se a busca fica dentro de um formulário e pode ficar vazia, diga no handoff, para o campo não ser obrigatório.
  • ⚠️ Lista antiga: não use a ❗Predictive dropdown [Deprecated] do Desktop. Use a propriedade Suggestions.
  • ⚠️ Dev Mode: o trecho de código segue o rótulo, o texto de ajuda, o Error, o Disabled e o Read only do design. O name é sempre "search-field", e a lupa desligada e as sugestões não aparecem no trecho.

Tabelas de propriedades sem as props só técnicas. "Padrão" é o valor usado quando nada é informado.

SearchField

Quando usar
  • Use o SearchField para buscar ou filtrar conteúdo (ex.: buscar um plano, filtrar uma lista de aparelhos, buscar uma pergunta na ajuda).
  • Use o Autocomplete quando o usuário precisa escolher uma opção de uma lista para preencher um formulário.
  • Use o TextField para um texto livre que não é uma busca.

¹ ℹ️ Sugestões: a lista abre embaixo do campo, com a largura dele, e mostra as sugestões que o getSuggestions devolve para o texto digitado. Diferente do TextField, no SearchField as sugestões funcionam também com defaultValue ou sem valor nenhum. Para o leitor de tela, o campo é uma caixa de combinação e a lista é anunciada com o rótulo do campo.

² ℹ️ Busca dentro de um Form: sem optional, o campo é obrigatório e mostra "Este campo é obrigatório" quando fica vazio. Numa busca que só filtra a tela, use o campo fora de um Form ou com optional.

ℹ️ Botão de apagar: o ✕ aparece à direita quando o campo tem texto. Ao tocar nele, o texto é apagado, o foco volta para o campo e as sugestões são recarregadas. Para o leitor de tela, o botão se chama "Apagar pesquisa" (o texto vem do tema e muda com o idioma). O espaço do botão fica reservado mesmo sem texto, para o campo não mudar de tamanho.

ℹ️ Ícones: a lupa e o ✕ são fixos e não podem ser trocados. A lupa pode ser escondida com withStartIcon={false}.
