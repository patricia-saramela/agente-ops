Skeletons

Os Skeletons são formas cinzas que piscam devagar no lugar do conteúdo enquanto ele carrega, desenhando o formato do que vai aparecer. Use quando o carregamento é curto e o layout da tela já é conhecido; há formas de linha, texto, círculo, item de lista e retângulo.

Componentes

Resumo

Formas cinzas que piscam devagar no lugar do conteúdo enquanto ele carrega, desenhando o formato do que vai aparecer (texto, imagem, linha de lista).

  • SkeletonLine: uma linha de 8px de altura, como uma linha de texto.
  • SkeletonText: um parágrafo de três linhas (as duas primeiras na largura toda e a última com 75%), com 16px entre elas.
  • SkeletonCircle: um círculo, como um avatar ou ícone.
  • SkeletonRow: um círculo de 40px seguido de uma linha, como um item de lista.
  • SkeletonRectangle: um retângulo, como uma imagem ou um card.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Skeletons

  • ⚠️ Altura do retângulo: informe a altura do Skeleton Rectangle em px. No código, sem height, ele depende da altura do elemento em volta.
  • ⚠️ Animação: no código, os skeletons sempre piscam. Não conte com a versão parada do Figma.
  • ⚠️ Dev Mode: os trechos de código usam valores fixos. O do Skeleton Circle mostra size={48}, mas o círculo do Figma e o padrão do código têm 40px. O do Skeleton Rectangle mostra sempre height={100}. No Mobile, só o Skeleton Circle tem trecho de código.
  • ⚠️ Leitor de tela: informe o texto de carregamento (ex.: "Carregando faturas") para um dos skeletons da tela.

Quando usar

Use o skeleton quando:

  • For o carregamento inicial do conteúdo.

Não use o skeleton quando:

  • O conteúdo que vai carregar é desconhecido (ex.: webviews de terceiros). Use um Spinner.
  • O carregamento é parcial e disparado por uma ação do usuário. Use um Spinner.
  • O carregamento não foi disparado por uma ação do usuário. Use a LoadingBar.

² ℹ️ Leitor de tela: com ariaLabel, o skeleton é anunciado como um conteúdo carregando. Numa tela com vários skeletons, dê o ariaLabel a um só (ou a um elemento em volta), para o leitor de tela não repetir o aviso.

⚠️ Animação sempre ligada: os skeletons piscam sem parar (ciclo de 1,5s), mesmo quando o sistema está configurado para reduzir movimento.

ℹ️ Cores: a cor muda sozinha conforme o fundo (default, brand, negative…). Os cantos seguem o arredondamento de contêiner do tema, menos o círculo.

Dúvidas reais respondidas pelo suporte

Dúvida: Há tempo padrão para exibir o Skeleton (carregamento de 1–2 minutos)? Resposta: O Design System não define tempo. Boas práticas: mostrar o skeleton só se o carregamento passar de ~100–200ms (evita flash), mantê-lo só enquanto o conteúdo não chega e, se passar de 8–10 segundos, trocar por Spinner, Progress Bar ou uma tela de Feedback.

Ref. #669 · 11/2025

Dúvida: Que carregamento usar quando não sei quanta informação vai carregar? Resposta: Use o Skeleton com um padrão intermediário e genérico, que depois carrega um empty state ou as informações. (O Loading Screen não é usado para carregar informações de funcionalidades.)

Ref. #1224 · 08/2026
