Menu

O Menu é um menu suspenso que abre a partir de um elemento, como um botão de ícone "mais opções", e mostra uma lista de ações. Use para agrupar ações secundárias sem ocupar espaço na tela; as opções podem ser separadas em seções.

Componentes

Resumo

Menu suspenso que abre a partir de um elemento (ex.: um botão de ícone "mais opções") e mostra uma lista de opções.

  • Menu: controla a abertura, a posição e o teclado. Recebe o elemento que abre o menu (renderTarget) e o conteúdo (renderMenu).
  • MenuItem: cada opção do menu.
  • MenuSection: agrupa opções, com uma linha divisória entre os grupos.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Menu

  • ⚠️ Posição: informe de qual elemento o menu abre e para qual lado. O código troca o lado sozinho quando não há espaço.
  • ⚠️ Dev Mode: o trecho de código que o Figma mostra no Dev Mode é sempre um exemplo fixo com duas opções; não reflete os itens do design.
Combinações de propriedades: o que o código faz

Nenhuma combinação de variantes do Figma conflita com o código.

Dúvidas reais respondidas pelo suporte

Dúvida: Há componentes no Design System equivalentes aos do iOS 26 usados num conceito? Resposta: System Ops mapeava os componentes novos do projeto. No caso mostrado, o equivalente é o Menu (sem o efeito "Liquid Glass").

Ref. #635 · 10/2025

Dúvida: Posso customizar o Menu com outros conteúdos? E usar o menu hambúrguer do Main Navigation Bar para outro conteúdo? Resposta: O Menu aceita algumas customizações (ex.: topo com avatar e textos; há exemplo no Playroom). O menu hambúrguer do Main Navigation Bar só existe para mostrar, em telas menores, os itens de navegação do desktop; se não há itens, ele nem aparece. Para abrir outro conteúdo a partir do header, use um Drawer acionado por outro elemento.
