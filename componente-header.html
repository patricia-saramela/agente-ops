Header (Header, Main Section Header)

O Header é o cabeçalho do topo de uma página, com pré-título, título e descrição, e o Header Layout é a área que o recebe, com fundo e breadcrumbs. Use no início de telas internas para dizer onde o usuário está. O Main Section Header é a versão maior, para a página principal de uma seção.

Componentes

Resumo

Header / HeaderLayout

Cabeçalho do topo de uma página, com pré-título, título e descrição. Usado no início de telas internas para dizer onde o usuário está.

  • Header: os textos do cabeçalho.
  • HeaderLayout: a área do topo da página que recebe o Header, com espaçamento, fundo (normal ou da marca), breadcrumbs e um conteúdo extra (slot).

MainSectionHeader / MainSectionHeaderLayout

Cabeçalho grande para as páginas principais de uma seção (ex.: a página inicial de "Conta" ou "Loja"), com título, descrição e um botão opcional.

  • MainSectionHeader: os textos e o botão.
  • MainSectionHeaderLayout: a área do topo que recebe o MainSectionHeader, com espaçamento e fundo (normal ou da marca). No desktop, o conteúdo ocupa a metade esquerda.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Header

  • ⚠️ Dev Mode: o trecho de código que o Figma mostra no Dev Mode só traz o Header (os textos). O fundo, os breadcrumbs, o espaçamento e o slot ficam no HeaderLayout e não aparecem no trecho.
  • ⚠️ Slot ao lado: só existe no desktop. No celular, o slot sempre fica abaixo do cabeçalho.
  • ⚠️ Cabeçalho no app nativo: dentro do app, o cabeçalho pode ser mostrado pelo próprio app; nesse caso, o HeaderLayout fica sem o header.
Combinações de propriedades: o que o código faz
CombinaçãoFigmaCódigo
Slot position=Bleed + Variant=DefaultExisteO bleed só tem efeito com variant="brand"; com fundo normal, o slot fica abaixo do cabeçalho, como no Default. ⚠️

MainSectionHeader

  • ⚠️ Dev Mode: o trecho de código que o Figma mostra no Dev Mode só traz o MainSectionHeader, sem o MainSectionHeaderLayout e sem o variant.
  • ⚠️ Botões: indique no handoff se o header tem botão e qual (primário ou secundário). O Figma mostra o Button Group sempre, e o trecho do Dev Mode não traz o button.
  • ⚠️ Desktop: no código, o conteúdo ocupa só a metade esquerda da tela no desktop.

Dúvidas reais respondidas pelo suporte

Dúvida: O Header mobile tem 32px de padding à direita e 16px à esquerda. Está certo? Posso zerar? Resposta: Está correto. No código, a margem é de 16px e o texto tem mais 16px de margem interna, para que textos longos quebrem melhor; no Figma isso aparece como 32px. Não altere. Sugestões de mudança passam pela liderança e por Ops, e no caso do Header dependem do time global.

Ref. #83 · 12/2024

Dúvida: Posso usar o componente Header para criar mais de um título na mesma página? Resposta: Pode haver vários cabeçalhos com hierarquias diferentes (ex.: cabeçalho da página + cabeçalhos de seção em páginas longas). Nunca use dois títulos principais (h1 / Main Section Header) na mesma página. Evite também barra de navegação grande seguida de cabeçalho robusto no app. Para títulos de seção, a melhor opção é usar o componente Title.

Ref. #611 · 10/2025

Dúvida: Posso tirar o padding esquerdo do header na web? Resposta: O header segue a largura da tela de ponta a ponta. Ajuste a largura do componente para a da tela e o espaçamento fica correto.
