Boxed

O Boxed é uma caixa com fundo e cantos arredondados que agrupa conteúdo. A variante define a cor de fundo, e os textos e componentes de dentro se adaptam sozinhos a ela. Use para destacar ou separar um bloco de conteúdo do resto da página.

Customização

Resumo

Caixa com fundo e cantos arredondados que agrupa conteúdo. A variante define a cor de fundo e o tema aplicado ao conteúdo de dentro: textos e componentes internos se adaptam automaticamente (por exemplo, texto claro sobre caixa brand).

Regras que não aparecem no Figma (pontos de atenção no handoff)

Boxed

  • ⚠️ Variantes a mais no código: se o design precisar de uma caixa com fundo alternativo ou sobre imagem, combine com quem desenvolve: as variantes alternative e media existem só no código.
  • ⚠️ Borda: no código, a borda só aparece na variante Default sobre fundo Default ou Alternative, e depende da configuração da marca.
  • ⚠️ Desktop: o Design System só tem ligação de código para o Boxed do Mobile. Se ele existir no biblioteca Desktop, o Dev Mode não mostra o trecho de código para ele.
Combinações de propriedades: o que o código faz

Nenhuma combinação de variantes do Figma conflita com o código.
