Select

O Select é o campo de formulário em que o usuário escolhe uma opção numa lista que abre ao tocar, como "Estado" ou "Tipo de documento". Use quando há muitas opções para mostrar como Radio Button; se a lista for muito longa e precisar de busca, use o Autocomplete.

Componentes

Resumo

Campo de formulário em que o usuário escolhe uma opção numa lista que abre ao tocar, como "Estado" ou "Tipo de documento". Mostra o rótulo, a opção escolhida, uma seta e, embaixo, um texto de ajuda ou de erro.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Select

  • ⚠️ Fundo de marca: não use o Select com Theme context=Brand ou Negative esperando essas cores: no código, o campo sempre tem o visual do fundo padrão.
  • ⚠️ Largura: o Figma Desktop desenha o campo com 496px, mas o código usa 328px por padrão no desktop (ou a largura toda, com fullWidth). Informe a largura desejada.
  • ⚠️ Lista no celular: no iOS e no Android, a lista é a nativa do sistema, não a do Figma Desktop.
  • ⚠️ Campo opcional: se o campo não for obrigatório, avise no handoff e diga se o rótulo deve mostrar "(opcional)".
  • ⚠️ Dev Mode: o trecho de código usa rótulo e opções fixos ("Label", "Option 1", "Option 2"); só helperText, error e disabled seguem o design.

ℹ️ O Select não aceita children.

Dúvidas reais respondidas pelo suporte

Dúvida: O Select aceita description nos itens da lista? Há estado "aberto" no Figma? Resposta: Não aceita description. O estado aberto não existe no Figma (só no código e na documentação); a sugestão foi levada ao time. Evoluções de componente exigem o fluxo no Figma, a necessidade confirmada e aprovação da liderança; o prazo depende do roadmap do time global.

Ref. #46 · 10/2024 · ⚠️ limitação atual

Dúvida: No Select aberto, qual sombra usar, qual a altura máxima e tem divider entre as opções? Resposta: No mobile (app), as opções são nativas do sistema. Na web (mobile ou desktop), as opções seguem o padrão do navegador, não as nativas de iOS/Android. A sombra já vem no componente; a altura depende da quantidade de opções (não há limite de itens, mas a partir de certa quantidade há rolagem; pense na experiência). Siga o padrão do componente (sem divider entre as opções).

Ref. #79 · 12/2024

Dúvida: Posso desenhar um visual próprio para o Select aberto na web? Resposta: Em aplicação web, as opções do Select seguem o sistema operacional ou o navegador: não precisa prever o visual no handoff, só listar as opções. (No app iOS, a seleção abre num sheet com radios.)

Ref. #770 · 01/2026

Dúvida: Como o Select mostra textos longos no mobile? Resposta: No estado aberto, o texto quebra em várias linhas, ocupando a largura da tela. As reticências aparecem só no estado fechado. O componente foi feito para opções curtas, e reticências são ruins para acessibilidade: evite textos longos e veja limites com o time de conteúdo.
