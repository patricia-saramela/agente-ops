Cartão de crédito (número, validade, CVV)

Campos de formulário

Resumo

CreditCardFields

Bloco pronto com os três campos do cartão de crédito: o número em cima e, embaixo, a validade e o CVV lado a lado. Usa o CreditCardNumberField, o CreditCardExpirationField e o CvvField, já com os rótulos, o espaçamento e a ligação entre eles (o CVV aceita 4 dígitos quando o cartão é American Express). Use dentro de um Form.

CreditCardExpirationField

Campo para a data de validade do cartão de crédito, no formato MM/AA (ex.: 08/29). Só aceita números, coloca a barra sozinho enquanto o usuário digita, abre o teclado numérico no celular e já valida se a data está completa e não venceu. Tem o mesmo visual do TextField e funciona sozinho ou dentro de um Form. Costuma ser usado junto com o CreditCardNumberField e o CvvField (ou todos juntos no CreditCardFields).

CreditCardNumberField

Campo para o número do cartão de crédito. Só aceita números, separa os dígitos em grupos de 4 enquanto o usuário digita, abre o teclado numérico no celular e mostra à direita o logo da bandeira (Visa, Mastercard ou American Express) assim que reconhece o número. Também valida o número sozinho. Tem o mesmo visual do TextField e funciona sozinho ou dentro de um Form. Costuma ser usado junto com o CreditCardExpirationField e o CvvField (ou todos juntos no CreditCardFields).

CvvField

Campo para o código de segurança do cartão (CVV). Só aceita números, abre o teclado numérico no celular e tem à direita um ícone de informação que abre uma explicação de onde fica o código no cartão. Valida sozinho a quantidade de dígitos. Tem o mesmo visual do TextField e funciona sozinho ou dentro de um Form. Costuma ser usado junto com o CreditCardNumberField e o CreditCardExpirationField (ou todos juntos no CreditCardFields).

Regras que não aparecem no Figma (pontos de atenção no handoff)

CreditCardExpirationField

  • ⚠️ Data de exemplo: use no design uma data que ainda não venceu (ex.: 08/29). A data do componente (07/11) daria erro no código.
  • ⚠️ Mensagem de erro: a data incompleta ou vencida mostra "Data inválida" sozinha. Se precisar de outra mensagem ou de outra regra (ex.: validade mínima), informe no handoff.
  • ⚠️ Campo vazio com foco: o código mostra "MM/AA" como texto de exemplo. O componente do Figma não tem esse estado.
  • ⚠️ Formulário de cartão: se o formulário tiver número, validade e CVV, avise se o foco deve passar sozinho de um campo para o outro (autoJump do Form).
  • ⚠️ Dev Mode: o trecho de código segue o rótulo, o texto de ajuda, o Error, o Disabled e o Read only do design. O name é sempre "credit-card-expiration-field".

CreditCardFields

  • ⚠️ Rótulos: no código, os rótulos são sempre "Número de cartão", "Expiração" e "CVV". Se o design usar outros textos, é preciso montar os três campos separados.
  • ⚠️ Personalização: texto de ajuda, campo opcional, desabilitado ou largura toda não existem no CreditCardFields. Se o design tiver algum deles, avise: o desenvolvimento vai usar os três campos separados.
  • ⚠️ Proporção dos campos de baixo: no código, a validade tem 60% e o CVV 40%, e o bloco tem 328px no desktop. O componente do Figma tem outras medidas.
  • ⚠️ Dev Mode: o trecho de código é sempre <CreditCardFields />, sem nenhuma prop. Ao clicar no campo da validade, o Dev Mode mostra um TextField, porque a instância interna é um Text Field.

CreditCardNumberField

  • ⚠️ Número de exemplo: use no design um número com a bandeira certa (ex.: 4111 1111 1111 1111 para Visa, 5555 5555 5555 4444 para Mastercard). O número do componente (1234…) não é de nenhuma bandeira.
  • ⚠️ Bandeiras aceitas: o código só reconhece Visa, Mastercard e American Express. Se o produto precisar de outras bandeiras (ex.: Elo, Hipercard), isso não existe no Design System: avise antes do desenvolvimento. Se alguma das três não for aceita, informe no handoff.
  • ⚠️ Logo da bandeira: o padrão do componente é a Mastercard. Se o número de exemplo for de outra bandeira, troque o Payment type na instância interna (ver o passo a passo no início). Não escolha uma bandeira diferente da do número: no código, o logo sempre segue os primeiros dígitos.
  • ⚠️ Formulário de cartão: se o formulário tiver número, validade e CVV, avise se o foco deve passar sozinho de um campo para o outro (autoJump do Form).
  • ⚠️ Dev Mode: o trecho de código segue o rótulo, o texto de ajuda, o Error, o Disabled e o Read only do design. O name é sempre "credit-card-number-field".

CvvField

  • ⚠️ Quantidade de dígitos: diga se o CVV tem 3 dígitos (Visa e Mastercard) ou 4 (American Express), ou se depende do cartão. No código, o campo sozinho exige 4 dígitos, a menos que o desenvolvimento passe outra quantidade.
  • ⚠️ Balão de ajuda: no código, é sempre um Popover, com botão X, que abre acima do ícone. No Mobile do Figma, o balão é um Tooltip; considere o Popover no design.
  • ⚠️ Bandeiras: se o American Express não for aceito, a explicação dele não aparece no balão. Informe no handoff quais bandeiras são aceitas.
  • ⚠️ Ícone: não troque o ícone de informação: no código, ele é fixo.

Comportamento no código (versão 18.0.0)

Tabelas de propriedades sem as props só técnicas. "Padrão" é o valor usado quando nada é informado.

CreditCardFields

Quando usar
  • Use o CreditCardFields quando o formulário pede os dados do cartão do jeito padrão, sem textos de ajuda nem rótulos próprios.
  • Use os três campos separados quando precisar trocar os rótulos, colocar texto de ajuda, deixar algum campo opcional, ocupar a largura toda ou mudar a organização dos campos.

ℹ️ Próximo campo: com autoJump no Form, o foco passa sozinho do número para a validade e da validade para o CVV, quando cada um é completado.

Quando o número começa como Visa, Mastercard ou American Express, o ícone gira e mostra o logo da bandeira; se o número mudar para outra bandeira, troca o logo; se deixar de ser uma bandeira reconhecida, volta ao ícone cinza. O ícone não pode ser trocado.

ℹ️ Valor: dentro de um Form, o onSubmit recebe o número só com os dígitos (values, ex.: '4111111111111111') e o texto com os espaços (rawValues).

ℹ️ Próximo campo: dentro de um Form com autoJump, quando o número é completado e está válido, o foco passa sozinho para o próximo campo (ex.: a validade).

CreditCardNumberField

Figma: biblioteca Desktop › Credit Card Number Field [D] · biblioteca Mobile › Credit Card Number Field

ℹ️ No Figma, o ícone à direita do campo é o ícone de cartão cinza no estado vazio e o _Resources/Card Icons (com Payment type) nos estados com número. No código, o ícone muda sozinho conforme o número digitado.

⚠️ Trocar a bandeira no Figma: o Payment type não aparece no painel do Credit Card Number Field, porque o ícone da bandeira é uma instância interna não exposta. Em todas as variantes, a bandeira padrão é a Mastercard. Para trocar:

  1. Selecione o Credit Card Number Field.
  2. Entre nas camadas (duplo clique, ou Ctrl/Cmd + clique) até selecionar o ícone da direita, a instância _Resources/Card Icons.
  3. No painel dessa instância, troque o Payment type para American Express, Mastercard ou Visa.

Isso só funciona nos estados Focused e Activated: no Inactive (campo vazio), o ícone é o cartão cinza, sem bandeira.

ℹ️ Sugestão para o design system: expor a instância _Resources/Card Icons no Credit Card Number Field, para o Payment type aparecer no painel do campo, junto com as outras propriedades.
