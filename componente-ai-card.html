AI Card (Community)

O AI Card é um cartão de uma linha com um texto fixo seguido de palavras que aparecem sendo digitadas, uma de cada vez, como numa sugestão de um assistente de IA. Use como ponto de entrada clicável para a conversa com o assistente (ex.: "Pergunte sobre sua fatura"). É um componente da Community, fora do núcleo do Design System.

Comunidade (componentes da marca no Design System)

Resumo

Cartão de uma linha com um texto fixo seguido de palavras que aparecem sendo digitadas, uma de cada vez, como numa sugestão de um assistente de IA (ex.: "Pergunte sobre " + "sua fatura", "seu plano", "roaming"). Cada palavra é digitada, fica um tempo na tela e é apagada para dar lugar à próxima; a última fica. Tem um ícone opcional à esquerda e uma borda que aceita cor ou degradê. Costuma ser clicável e levar à conversa com o assistente.

ℹ️ Comunidade: é um componente do Design System Community: fica no pacote do Design System para ser compartilhado entre projetos, mas não faz parte do núcleo do design system.

ℹ️ Importação: importe CommunityAiCard de o pacote do Design System. O mesmo componente também existe como AiCard em o pacote "community" do Design System, mas o próprio Design System avisa que esse caminho tem problemas com algumas versões do Next.js.

Regras que não aparecem no Figma (pontos de atenção no handoff)

CommunityAiCard

  • ⚠️ Texto e palavras: separe no handoff o texto fixo (ex.: "Pergunte sobre ") das palavras animadas (ex.: "sua fatura", "seu plano", "roaming"), no máximo 4. Diga qual palavra fica no fim. Não é preciso escrever o | do cursor: ele aparece sozinho.
  • ⚠️ Ícone: para trocar o raio, entre nas camadas do cartão e troque a instância do ícone (ele não aparece no painel de propriedades). Se a tela não tem ícone, informe no handoff.
  • ⚠️ Borda: se a borda for um degradê, informe as cores (o Figma só tem a cor sólida).
  • ⚠️ Clique: diga para onde o cartão leva.
  • ⚠️ Sem Code Connect: o Dev Mode não mostra o código do CommunityAiCard. Informe tudo no handoff.

¹ ℹ️ Animação: as letras são digitadas em velocidades que variam um pouco, para parecer natural, com um cursor (|) no fim; o cursor pisca enquanto a palavra fica parada e some quando a última palavra termina. A animação só roda enquanto o cartão está visível na tela. Espaços nas pontas das palavras e palavras vazias são ignorados.

² ℹ️ Apagar só o necessário: mesmo sem deleteChars, se a próxima palavra começa com a mesma letra, a primeira letra fica; e, ao digitar a próxima, o que as duas palavras têm em comum no começo não é digitado de novo.

³ ℹ️ Ação: use uma, e só uma, entre onPress, to e href. Sem nenhuma, o cartão não é clicável (sem hover nem estado pressionado). Também aceita as outras props de link do Touchable (loadOnTop, onNavigate, fullPageOnWebView, replace).

⁴ ℹ️ Leitor de tela: o texto animado não é lido (para não ser anunciado letra por letra). O cartão é lido de uma vez, com o aria-label, que, por padrão, é o text seguido da última palavra (ex.: "Pergunte sobre roaming").

ℹ️ Movimento reduzido: quando o aparelho está configurado para reduzir animações, o cartão mostra direto a última palavra, sem digitação nem cursor.

ℹ️ Tamanho: o cartão ocupa a largura do espaço onde está, com no mínimo 288px de largura e 64px de altura, 16px de espaço interno e 8px entre o ícone e o texto. O espaço da palavra mais longa fica reservado, então o cartão não muda de tamanho durante a animação.

ℹ️ Clicável: com uma ação, o fundo muda no hover e ao pressionar, e aparece um contorno ao receber o foco pelo teclado.

ℹ️ Figma: no Figma, o componente se chama AI Card (sem o prefixo Community/ dos outros) e fica na página Community do biblioteca Desktop e do biblioteca Mobile. Não tem Code Connect: o Dev Mode não mostra o trecho de código dele. Ver a comparação em figma-ai-card.

No Figma: propriedades e diferenças Desktop × Mobile

CommunityAiCard

Figma: biblioteca Desktop › AI Card [D] · biblioteca Mobile › AI Card

ℹ️ No Figma, o AI Card é o cartão parado: um ícone de raio, um texto com o cursor (|) escrito no fim e uma borda de cor sólida. A descrição do componente diz que ele é "um componente clicável com animação visual, que atua como entry point para a interação com funcionalidades de IA", usado no Pra Você, e aponta para o arquivo de specs. O nome não tem o prefixo Community/ dos outros componentes da página.

ℹ️ O AI Card não tem Code Connect no Desktop nem no Mobile: o Dev Mode não mostra o trecho de código do CommunityAiCard.
