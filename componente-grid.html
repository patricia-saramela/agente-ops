Grid / GridItem

Layout

Resumo

Grade para organizar conteúdos em linhas e colunas, com espaço entre eles (ex.: uma vitrine de produtos, uma galeria de fotos, um painel com cartões de tamanhos diferentes).

  • Grid: a grade. Define as colunas e as linhas, o espaço entre elas e o alinhamento dos itens.
  • GridItem: um item da grade, quando ele precisa ocupar mais de uma célula, começar numa posição específica ou ter um alinhamento próprio. Itens simples não precisam de GridItem: qualquer conteúdo dentro do Grid já ocupa uma célula.

ℹ️ Tipo de layout: o Design System tem dois tipos de componentes de layout. Os orientados à página (ResponsiveLayout e GridLayout) montam a estrutura da tela: margens e colunas da página. Os orientados a componentes (Grid e HorizontalScroll) organizam um grupo de itens dentro dessa estrutura. O Grid é do segundo tipo.

Comportamento no código (versão 18.0.0)

Tabelas de propriedades sem as props só técnicas. "Padrão" é o valor usado quando nada é informado.

¹ ℹ️ Colunas automáticas: com columns={{minSize: 160}}, a grade cria quantas colunas de pelo menos 160px couberem na largura, e elas dividem o espaço que sobra. Em telas menores que o minSize, a coluna ocupa a largura toda. O maxSize limita o tamanho máximo (padrão: dividir o espaço igualmente). Sem columns, a grade tem uma coluna só.

² ℹ️ Espaço por tamanho de tela: gap={{mobile: 8, desktop: 24}} usa 8px no celular e 24px no desktop; sem tablet, o tablet usa o valor do celular. gap={[16, 24]} usa 16px entre as colunas e 24px entre as linhas.

³ ℹ️ Lista: para uma lista de itens (ex.: produtos), use as="ul" no Grid e as="li" em cada GridItem. O role="list" entra sozinho, para o leitor de tela anunciar a quantidade de itens também no Safari.

⁴ ⚠️ Ordem: o order muda só a posição na tela. O leitor de tela e o teclado seguem a ordem do código, então use com cuidado para não confundir a navegação.

ℹ️ Figma: o Grid não existe no Figma. No design, o mesmo resultado é feito com o auto layout do frame: a direção e a quebra de linha (Wrap) organizam os itens em linhas e colunas, e o espaçamento do auto layout equivale ao gap. Para colunas fixas, use as layout grids do frame. No handoff, diga o número de colunas (ou o tamanho mínimo de cada uma), o espaço entre os itens em cada tamanho de tela e quais itens ocupam mais de uma célula.

ℹ️ Sem testid padrão: diferente da maioria dos componentes, o Grid e o GridItem não têm testid padrão.
