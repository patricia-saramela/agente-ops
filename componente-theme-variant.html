Theme Variant (fundo e cores)

O Theme Variant informa aos componentes de dentro qual é o fundo onde eles estão, para que ajustem as cores sozinhos, como um botão sobre o fundo da marca. Use ao colocar componentes sobre fundos de marca ou alternativos; no Figma, equivale à propriedade Theme context.

Utilitários

Resumo

Informa aos componentes de dentro qual é o fundo onde eles estão, para que ajustem as cores sozinhos (ex.: um botão sobre fundo da marca usa as cores próprias para esse fundo). É o equivalente, no código, à propriedade Theme context dos componentes do Figma.

  • ThemeVariant: define o fundo para todo o conteúdo de dentro.
  • useThemeVariant: hook que devolve o fundo atual, para usar em componentes próprios.

Comportamento no código (versão 18.0.0)

Tabelas de propriedades sem as props só técnicas. "Padrão" é o valor usado quando nada é informado.

useThemeVariant

Não recebe parâmetros. Devolve 'default', 'brand', 'negative', 'alternative' ou 'media'. Se o fundo foi definido como 'inverse', devolve 'brand'.

⚠️ O ThemeVariant não pinta o fundo: ele só avisa os componentes. A cor de fundo precisa ser aplicada à parte. Componentes que já têm fundo próprio, como o Boxed com variant, já definem o ThemeVariant para o conteúdo deles.

ℹ️ O valor vale para tudo que está dentro, até o próximo ThemeVariant. Fora de qualquer ThemeVariant, o fundo é 'default'.

ℹ️ Figma: não é um componente no Figma. O equivalente é a propriedade Theme context de cada componente, com os valores Default, Brand, Negative e Media (o Alternative não existe em todos).
