List (Row, Boxed Row, listas)

Componentes

Resumo

Row / BoxedRow

Linha de lista com título e, opcionalmente, ícone ou imagem à esquerda, textos secundários, detalhe, badge e um controle à direita (seta, switch, checkbox, radio ou botão de ícone). Usada em listas de opções, configurações e menus de navegação.

  • Row: linha simples, separada das outras por uma linha divisória. Vai dentro de um RowList.
  • BoxedRow: a mesma linha dentro de uma caixa. Vai dentro de um BoxedRowList.

As duas têm as mesmas props. O BoxedRow tem, a mais, variant e selected.

RowList / BoxedRowList

Contêineres de lista que agrupam linhas.

  • RowList: agrupa Row, com linhas divisórias entre elas.
  • BoxedRowList: agrupa BoxedRow, cada uma numa caixa, com 16px de espaço entre elas.

UnorderedList / OrderedList / ListItem

Listas de texto com marcadores, para conteúdo corrido (ex.: benefícios de um plano, passos de um processo).

  • UnorderedList: lista com marcadores (pontos).
  • OrderedList: lista numerada.
  • ListItem: cada item da lista.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Row

  • ⚠️ Mobile: no Figma Mobile, o tipo de asset, a tag e o conteúdo da direita ficam escondidos dentro da instância List Structure; confira dentro dela.
  • ⚠️ Lista compacta: o tamanho dos textos vem da lista (RowList small), não de cada linha.
  • ⚠️ Dev Mode: o trecho de código que o Figma mostra no Dev Mode usa a prop extra para o slot, mas essa prop não existe no código; o certo é slot.

  • ⚠️ Níveis: para itens de segundo ou terceiro nível, indique no handoff quais itens ficam dentro de quais.
  • ⚠️ Tamanho do texto: o item não define o tamanho do texto no código; informe o estilo de texto usado.
Combinações de propriedades: o que o código faz

Nenhuma combinação de variantes do Figma conflita com o código.

Dúvidas reais respondidas pelo suporte

Dúvida: Numa lista de Rows, depois que o cliente seleciona uma opção, as outras ficam desabilitadas ou somem? Resposta: Consulte a demo interativa do componente na documentação do Design System para ver o comportamento.

Ref. #92 · 12/2024

Dúvida: Numa Row, o Icon Button fica a 28px da margem final, e Radio/Checkbox a 16px. Está certo? Resposta: Sim. O espaço maior considera a área do Icon Button (que pode ter fundo sólido) e a área mínima de clique de 48px.

Ref. #147 · 02/2025

Dúvida: Para que serve a opção Centered da Row, que não aparece no Playroom? Resposta: Use Centered só quando a Row tem uma linha (apenas título e detail). Ela centraliza o asset e a linha do título. Com mais linhas, não use.

Ref. #176 · 02/2025

Dúvida: Numa Row com dois dados de mesmo peso, posso mudar o token do subtitle para text secondary ou usar a description em duas linhas? Resposta: Não. Não se alteram manualmente os tokens de cor dos componentes: siga a hierarquia de tokens (o subtitle usa TextPrimary). Não é possível fazer quebra de linha manual na Row. Valide padrões de uso com Pesquisa e Evolução e mantenha as bibliotecas atualizadas.

Ref. #198 · 03/2025

Dúvida: Na tela de sucesso, se o texto de uma Row for longo, posso usar reticências em vez de quebrar a linha? Resposta: Evite reticências. O comportamento padrão é quebrar a linha. Pelas diretrizes de conteúdo e acessibilidade, reticências deixam a informação incompleta e podem ser ignoradas pelo leitor de tela.

Ref. #318 · 05/2025

Dúvida: A imagem 1:1 da Row mobile tem 64px, como no desktop. Posso usar 40px? Resposta: Sim, pode usar 40px. Para mudar, altere o gap da camada Change "Space Between": como o aspect ratio é 1:1, altura e largura se ajustam juntas.

Ref. #474 · 08/2025

Dúvida: O detail da Row quebra dentro da Success Feedback Screen [D]. Aumento a largura do conteúdo? Resposta: O detail foi pensado para textos curtos. A Seção C (onde fica o detail) não deve passar de 40% da largura da linha; acima disso, o detail vira multilinha. Para textos maiores, use description, e valide com Pesquisa e Evolução.

Ref. #506 · 09/2025

Dúvida: No desktop, posso usar Rows lado a lado? A Row pode não ter Title? Resposta: Rows só podem ser aplicadas em formato de lista (uma embaixo da outra). Para opções lado a lado, use o Media Card (ex.: com checkbox no top actions). O Title é o único item obrigatório da Row.

Ref. #789 · 01/2026

Dúvida: Na Row, posso usar o subtitle com textSecondary para o preço "De" e a description com textPrimary para o "Por"? Resposta: Não se troca o preset de cor da Row. Alternativa: desenhe o "De/Por" num frame e use-o no slot, desligando subtitle e description. Não coloque botão dentro do slot: a Row tem duas interações possíveis (OnPress na área principal e Control, ex.: checkbox) e um botão no slot conflita com o OnPress. Use a própria área de OnPress para "mais detalhes".

Ref. #911 · 03/2026

Dúvida: Grupos de Rows + input num novo visual de loja. Há impeditivo? Resposta: O app já tem um padrão para esse tipo de layout. Criar um novo padrão para algo que já existe precisa passar por Pesquisa e Evolução. Do lado de System não há impedimento.

Ref. #937 · 03/2026

Dúvida: Na Zone A da Row, o Circle com ícone vem na cor da marca. Posso usar fundo cinza? Resposta: O Circle usa as cores da marca. O padrão em produção para esses fluxos é usar o ícone sem o fundo (ex.: central de faturas).

Ref. #969 · 04/2026

Dúvida: Posso ter um Button Link no slot e um Icon Button na lateral da Row? Resposta: A Row pode ter duas interações: o Icon Button e a área principal. O link fica figurativo: cerca de 90% da Row é área clicável e 10% fica para o Icon Button.

Ref. #978 · 04/2026

Dúvida: Posso usar reticências no nome longo de uma assinatura na Row? Resposta: Não é recomendado: reticências são má prática, especialmente para acessibilidade. Busque com o time de conteúdo uma forma de encurtar o texto.

Ref. #987 · 04/2026

Dúvida: A imagem da Row no desktop fica com fundo branco? Resposta: Só se a imagem tiver fundo branco; não é padrão do componente.

Ref. #1042 · 05/2026

Dúvida: Posso pôr botões (tipo chips) dentro de um Boxed Row (FAQ)? Resposta: Dá para fazer, mas o tamanho e o espaçamento dos botões ficam pouco acessíveis (na Row, duas ações lado a lado são separadas por divider). Sugestão: mantenha os chips fora do box, no tamanho normal.

Ref. #1089 · 06/2026

Dúvida: Qual componente de código corresponde ao Boxed Row com switch do Figma? Resposta: É o Boxed Row List do Design System, usado com o switch.

Ref. #1129 · 06/2026

Dúvida: Os ícones do List Item mobile e desktop parecem diferentes. Resposta: Use no mobile o componente com o mesmo nome do desktop (Unordered List › List Item), que tem o mesmo bullet. A falha ao desligar "Last item" é provavelmente bug do Figma.

Ref. #1186 · 07/2026

Dúvida: Posso usar o ícone de fundo quadrado (como no Data Card snap da nova versão do app) também na web? Resposta: Sim, faz sentido para consistência. No mobile, selecione Squared em icon background, ajuste o corner do Square com a variable mediaSmall e use os tokens neutralLow (fundo) e neutralHigh (ícone). Na Row desktop do Figma ainda não há essa opção: use o Circled Icon com esses tokens e indique no handoff. No código, os devs usam o Square com raio de 12px.
