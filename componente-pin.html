Pin Field

O Pin Field é o campo para digitar um código curto, um algarismo em cada caixinha, como o código de 6 dígitos recebido por SMS. Use em verificações de identidade e confirmações; o foco passa sozinho para a próxima caixinha, e colar o código preenche todas.

Campos de formulário

Resumo

Campo para o usuário digitar um código curto, um algarismo em cada caixinha (ex.: o código de 6 dígitos recebido por SMS). O foco passa sozinho para a próxima caixinha a cada algarismo, e colar o código inteiro preenche todas de uma vez. No celular, abre o teclado numérico e pode preencher o código do SMS sozinho (readSms). Também pode esconder o código, como uma senha (hideCode). Funciona sozinho ou dentro de um Form.

Regras que não aparecem no Figma (pontos de atenção no handoff)

PinField

  • ⚠️ Texto que explica o campo: o Pin Field não tem rótulo. Desenhe um título ou texto acima das caixinhas (ex.: "Digite o código de 6 dígitos que enviamos por SMS") e diga no handoff que é ele que dá nome ao campo.
  • ⚠️ Código incompleto e código errado: o código só mostra erro sozinho com o campo vazio. Desenhe e informe as mensagens para código incompleto e para código incorreto (ex.: "Código incorreto. Confira o SMS e tente de novo."): o time de desenvolvimento mostra essas mensagens com o Error e o Helper text.
  • ⚠️ Código do SMS: diga se o código deve ser preenchido sozinho a partir do SMS. Isso vem ligado por padrão quando o código não é escondido (Hide Pin=False).
  • ⚠️ Dev Mode: o trecho de código segue o Length, o Hide Pin, o texto de ajuda, o Error, o Disabled e o Read only do design. O name é sempre "pin-field" e o aria-label é sempre "PIN": informe o nome certo no handoff.

Comportamento no código (versão 18.0.0)

Tabelas de propriedades sem as props só técnicas. "Padrão" é o valor usado quando nada é informado.

PinField

Quando usar
  • Use o PinField para códigos curtos só com números: código de verificação por SMS ou e-mail, PIN de 4 dígitos.
  • Use o PasswordField para senhas com letras, números e símbolos.
  • Use o IntegerField para um número digitado num campo só (ex.: uma quantidade).

¹ ℹ️ Código do SMS: com readSms, no Chrome do Android, o campo pede ao sistema o código que chega por SMS e preenche as caixinhas sozinho. No iOS, o teclado sugere o código recebido. Para isso, o SMS precisa seguir o formato que o sistema reconhece (o time de desenvolvimento define o texto do SMS). Com hideCode, o readSms fica desligado, a menos que seja ligado de propósito.

² ⚠️ Erro e validação: o PinField não aceita validate nem optional: dentro de um Form, ele é sempre obrigatório e só valida ao enviar. Com o campo vazio, mostra "Este campo é obrigatório"; um código incompleto (ex.: 3 de 6 algarismos) passa na validação. Para conferir o código, use o onSubmit do Form e mostre o erro com error e helperText. Com erro, só o texto embaixo fica vermelho: as caixinhas continuam com a borda normal.

³ ⚠️ Sem rótulo visível: o PinField não tem label. Coloque um título ou texto na tela explicando o que digitar, e ligue-o ao campo com aria-labelledby (ou use aria-label). Para o leitor de tela, o campo é um grupo, e cada caixinha é lida como "Dígito 1 de 6", "Dígito 2 de 6" e assim por diante.

ℹ️ Digitação: cada caixinha aceita um algarismo (só de 0 a 9). Ao digitar, o foco vai para a próxima; ao apagar, volta para a anterior. Não dá para pular caixinhas vazias: tocar numa caixinha depois da primeira vazia leva o foco para a primeira vazia. As setas do teclado andam entre as caixinhas. Colar ou preencher automaticamente o código inteiro preenche todas.

ℹ️ Aparência: cada caixinha tem 48px de largura, com o algarismo centralizado. A caixinha com foco tem a borda na cor de destaque. Quando não cabem na largura, as caixinhas passam para a linha de baixo. O campo não tem versão menor (small) nem de largura toda (fullWidth).
