Accordion (Accordion, Boxed Accordion)

O Accordion é uma lista de seções expansíveis: cada item tem um cabeçalho clicável que mostra ou esconde o conteúdo. Use quando houver vários blocos de informação que o usuário só precisa abrir sob demanda, como perguntas frequentes, economizando espaço na tela. O Boxed Accordion é a mesma coisa com cada item numa caixa.

Componentes

Resumo

Accordion / BoxedAccordion

Contêiner que agrupa itens expansíveis (AccordionItem / BoxedAccordionItem). Usado quando houver uma lista de seções que o usuário pode abrir e fechar para ver mais conteúdo, economizando espaço na tela.

  • Accordion: os itens ficam separados por um Divider.
  • BoxedAccordion: os itens ficam empilhados em caixas, com espaçamento de 16 (Stack).

AccordionItem / BoxedAccordionItem

Item expansível de um accordion. Tem um cabeçalho clicável (título, subtítulo, asset, detalhe e um chevron) que mostra ou esconde o conteúdo. É usado dentro de um componente Accordion (AccordionItem) ou de um BoxedAccordion (BoxedAccordionItem).

Regras que não aparecem no Figma (pontos de atenção no handoff)

Accordion

  • ⚠️ Small e Auto collapse valem para o grupo: no código, todos os itens de um mesmo accordion são compactos ou não, e o Auto collapse vale para o grupo inteiro. No Figma, mantenha esses valores iguais em todos os itens do mesmo accordion.
  • ⚠️ Itens abertos: indique no handoff quais itens começam abertos. No código isso é definido no contêiner, pela posição do item.
  • ⚠️ Accordion e Boxed Accordion não se misturam: use só itens de um tipo em cada grupo.
  • ⚠️ Dev Mode: o trecho de código que o Figma mostra no Dev Mode não inclui small nem os itens abertos, mesmo quando a variante usa Small ou Open.
  • ⚠️ Boxed Accordion no Mobile: o Design System só tem ligação de código (Code Connect) para o Boxed Accordion do Desktop. Se ele existir no biblioteca Mobile, o Dev Mode não mostra o trecho de código para ele.
Combinações de propriedades: o que o código faz

Nenhuma combinação de variantes do Figma conflita com o código. O Custom content só existe com Open ligado, o que é coerente: o conteúdo só aparece com o item aberto.

Dúvidas reais respondidas pelo suporte

Dúvida: Rows dentro do slot do Accordion levam padding lateral ou se alinham com Negative Box? Resposta: Alinhe com Negative Box. Dentro de um Drawer, pode haver dois Negative Box: o externo remove o espaçamento lateral do Drawer e o interno remove o padding do conteúdo do Accordion. Cada um deve compensar só o padding do seu container imediato.
