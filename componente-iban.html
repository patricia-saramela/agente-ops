IBAN Field

O IBAN Field é o campo para o usuário digitar um IBAN, o número internacional de conta bancária. Use em formulários que pedem dados bancários internacionais: ele formata o número em grupos de 4, coloca as letras em maiúsculas e avisa se o IBAN for inválido.

Campos de formulário

Resumo

Campo para o usuário digitar um IBAN, o número internacional de conta bancária (ex.: ES79 2100 0813 6101 2345 6789). Enquanto o usuário digita, o campo coloca as letras em maiúsculas e separa o número em grupos de 4. Ao validar, confere se o IBAN é válido: se não for, mostra "IBAN incorreto". Tem o mesmo visual do TextField e funciona sozinho ou dentro de um Form.

Regras que não aparecem no Figma (pontos de atenção no handoff)

IbanField

  • ⚠️ Mensagem de erro: o código já mostra "IBAN incorreto" quando o IBAN não é válido. Se precisar de outro texto, ou de outras regras (ex.: só contas de um país), informe as regras e as mensagens.
  • ⚠️ Campo opcional: hoje, um campo de IBAN opcional deixado em branco mostra "IBAN incorreto" e não deixa enviar o formulário. Se o IBAN for opcional na tela, avise no handoff para o time de desenvolvimento tratar o caso.
  • ⚠️ Formato: use no design o IBAN em maiúsculas e em grupos de 4 (ex.: ES79 2100 0813 6101 2345 6789), que é como o código mostra.
  • ⚠️ Dev Mode: o trecho de código segue o rótulo, o texto de ajuda, o Error, o Disabled e o Read only do design. O name é sempre "iban-field", e o Prefix não aparece no trecho, mesmo ligado no design: informe o prefixo no handoff.

IbanField

Quando usar
  • Use o IbanField quando o campo recebe um IBAN (ex.: conta para débito automático ou reembolso em países que usam IBAN).
  • Use o TextField para dados bancários sem IBAN, como agência e conta no Brasil.

¹ ℹ️ Formato: o campo aceita só letras e algarismos. As letras viram maiúsculas, e a cada 4 caracteres entra um espaço. O valor guardado (no value do onChangeValue e no onSubmit do Form) não tem espaços: ES7921000813610123456789. O texto com espaços fica no rawValue.

² ℹ️ Validação do IBAN: dentro de um Form, o campo confere o código do país (2 letras), os 2 dígitos de controle, o tamanho (para Espanha, Reino Unido, Alemanha e Brasil) e a conta de verificação do IBAN. Se algo estiver errado, mostra "IBAN incorreto" (o texto vem do tema e muda com o idioma). O validate só roda quando o IBAN é válido.

³ ⚠️ Campo opcional vazio: a validação do IBAN roda mesmo com o campo vazio. Então, um IbanField com optional que o usuário deixa em branco mostra "IBAN incorreto" ao perder o foco e não deixa enviar o Form. Hoje não há prop para mudar isso.

⁴ ℹ️ Tamanho máximo: o campo não deixa digitar além do tamanho do IBAN do país: 24 caracteres na Espanha, 22 no Reino Unido e na Alemanha e 29 no Brasil, sem contar os espaços. Para os outros países, o limite é 32, o maior IBAN que existe.
