Image

O Image mostra uma imagem com os cantos arredondados do tema, com proporção fixa, formato redondo ou tamanho definido. Use para qualquer imagem solta na tela: ele mostra um esqueleto enquanto carrega e uma caixa com ícone se a imagem falhar.

Primitivos

Resumo

Mostra uma imagem com os cantos arredondados do tema. Pode ter uma proporção fixa (aspectRatio, ex.: '16:9'), ser redonda (circular) ou ter largura e altura definidas. Enquanto carrega, mostra um esqueleto animado; se a imagem não carregar, mostra uma caixa cinza com um ícone de imagem quebrada. Os cards, o Hero e outros componentes do Design System usam o Image por dentro.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Image

  • ⚠️ Proporção: o trecho do Dev Mode não leva a proporção nem o tamanho. Informe a proporção (ex.: 16:9) ou a largura e a altura. Sem isso, a imagem aparece com a proporção original e a largura toda.
  • ⚠️ Texto alternativo: se a imagem passa uma informação (ex.: a foto de um aparelho à venda), informe o texto que o leitor de tela deve ler. Se é decorativa, diga isso.
  • ⚠️ Proporção 21:9: funciona no código, mas não é uma opção pronta. Informe para o time de desenvolvimento passar o número.
  • ⚠️ Dev Mode: o trecho de código segue o Type (só o Circular), o Border radius e o Border do design. O endereço da imagem é sempre um exemplo.

¹ ℹ️ Tamanho: sem width e sem height, a imagem ocupa a largura toda do espaço onde está. Com só um dos dois e uma proporção (aspectRatio), o outro é calculado. Com só um dos dois e sem proporção, a imagem mantém a proporção original e aparece inteira (objectFit: 'contain'). Com os dois, a imagem tem esse tamanho exato e é cortada para preencher (objectFit: 'cover').

² ℹ️ Cantos: por padrão, os cantos usam o raio de contêiner do tema. Dentro de alguns componentes do Design System (como cards), o raio segue o que o componente define. Com circular, a imagem é sempre redonda.

³ ⚠️ Esqueleto e erro só com tamanho conhecido: o esqueleto de carregamento e a caixa de erro só aparecem quando o tamanho da imagem é conhecido antes de carregar: com aspectRatio, com circular ou com width e height juntos. Sem isso, a imagem simplesmente não aparece enquanto carrega ou se der erro. A caixa de erro muda de cor com o fundo (brand, negative etc.) e, nas skins da marca, usa um ícone próprio.

⁴ ⚠️ Texto alternativo: o alt vazio é o padrão. Se a imagem passa uma informação (ex.: a foto de um aparelho à venda), preencha o alt com o que a imagem mostra.
