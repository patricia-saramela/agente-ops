Breadcrumbs

Os Breadcrumbs mostram onde a página atual está na hierarquia do site (ex.: Início / Seção / Subseção), com links para os níveis anteriores. Use em páginas internas, para que o usuário volte facilmente a uma seção acima.

Componentes

Resumo

Componente de navegação que mostra onde a página atual está dentro da hierarquia do site (ex.: Início / Seção / Subseção). Cada nível anterior é um link, o último item é a página atual, e é exibido em uma cor secundária e sem link. Usado em páginas internas para que o usuário volte facilmente aos outros níveis.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Breadcrumbs

  • ⚠️ Mais de 4 níveis: o código aceita qualquer quantidade, mas o Figma só tem até 4. Se o fluxo tiver mais níveis, desenhe o caso e combine com quem desenvolve.
  • ⚠️ Página atual: é sempre o último item, sem link. Não repita a página atual como um nível anterior.
  • ⚠️ Dev Mode: o trecho de código que o Figma mostra no Dev Mode é sempre o mesmo exemplo fixo (2 níveis), qualquer que seja a variante escolhida.
Combinações de propriedades: o que o código faz

Nenhuma combinação de variantes do Figma conflita com o código.

Comportamento no código (versão 18.0.0)

Tabelas de propriedades sem as props só técnicas. "Padrão" é o valor usado quando nada é informado.

NavigationBreadcrumbs

Propriedades
PropValores aceitosPadrãoDescrição
title (obrigatória)Nome da página atual, exibido no fim da trilha, sem link.
breadcrumbs (obrigatória)Níveis anteriores à página atual, na ordem do mais alto para o mais baixo. Cada item vira um link seguido do separador /. Ver campos abaixo.
Itens de breadcrumbs
PropValores aceitosPadrãoDescrição
title (obrigatória)Texto do link.
url (obrigatória)Destino do link. A navegação usa o Link do roteador configurado no tema (navegação interna, via to).
onNavigateFunção executada no clique, antes da navegação (ex.: enviar evento de analytics).

ℹ️ O componente não aceita children: todo o conteúdo vem de title e breadcrumbs.

ℹ️ A estrutura segue o padrão de acessibilidade do W3C: um <nav> com uma lista ordenada (<ol>). O item da página atual recebe aria-current="page" e não é clicável. Os separadores / são ignorados pelo leitor de tela.

⚠️ A página atual não deve ser incluída dentro da propriedade breadcrumbs, ela já é exibida a partir da props title.
