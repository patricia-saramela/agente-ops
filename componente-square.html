Square

Primitivos

Resumo

Forma quadrada, com cantos arredondados, que serve de fundo para outro conteúdo: uma cor, uma imagem ou um ícone centralizado (ex.: o logo de um app num quadrado). O conteúdo (children) fica sempre centralizado. É uma peça básica: o Design System usa o Square dentro de outros componentes, e ele pode ser usado direto nas telas.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Square

  • ⚠️ Sem Code Connect: o Dev Mode não mostra o código do Square. Informe o tamanho, a cor de fundo do tema (ex.: brandLow), o conteúdo (ícone ou imagem) e se tem borda.
  • ⚠️ Cantos: o código usa o raio de contêiner do tema, até no máximo 25% do tamanho. Se o design usa outro raio, informe o valor.

Comportamento no código (versão 18.0.0)

Tabelas de propriedades sem as props só técnicas. "Padrão" é o valor usado quando nada é informado.

Square

Propriedades
PropValores aceitosPadrãoDescrição
size🎨 Largura e altura do quadrado (ex.: 40 ou '3rem'). Sem ela, o quadrado fica do tamanho do conteúdo.
background🎨 Fundo completo, no formato do background do CSS (ex.: um degradê). Não pode ser usado junto com backgroundColor e backgroundImage.¹
backgroundColor🎨 Cor de fundo (ex.: skinVars.colors.brandLow).¹
backgroundImage🎨 Endereço de uma imagem de fundo. A imagem cobre o quadrado todo, centralizada e cortada nas bordas.¹
border🎨 Borda de 1px. Com true, usa a cor de borda do tema; com um texto, usa essa cor (ex.: skinVars.colors.borderLow).
borderRadiusraio de contêiner do tema, até 25% do tamanho🎨 Arredondamento dos cantos (ex.: '8px' ou '0' para cantos retos).²
childrenConteúdo dentro do quadrado, centralizado na horizontal e na vertical (ex.: um ícone).

¹ ℹ️ Fundo: use ou o background, ou o backgroundColor e o backgroundImage. Com os dois últimos juntos, a imagem fica por cima da cor (a cor aparece onde a imagem é transparente ou enquanto ela carrega).

² ℹ️ Cantos: sem borderRadius, os cantos usam o raio de contêiner do tema, mas nunca passam de 25% do tamanho. Assim, um quadrado pequeno não vira um círculo.

ℹ️ Conteúdo maior que o quadrado: o Square não corta o conteúdo. Se o ícone ou a imagem dentro dele forem maiores que o size, eles passam da borda.

No Figma: propriedades e diferenças Desktop × Mobile

Square

Figma: biblioteca Desktop › Square [D] · biblioteca Mobile › Square

ℹ️ No Figma, o Square tem 40 × 40 e quatro variantes de conteúdo: ícone, imagem, vazio e slot, como o Circle. A cor de fundo não é uma propriedade: é mudada direto na camada.

ℹ️ O Square não tem Code Connect no Desktop nem no Mobile: o Dev Mode não mostra o trecho de código do Square.
