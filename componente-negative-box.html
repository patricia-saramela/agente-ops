NegativeBox

O NegativeBox puxa o conteúdo 16px para fora dos lados, avançando sobre a margem de onde ele está. Use para alinhar componentes que já têm espaço interno com o resto da tela; o caso mais comum é uma lista (Row List), para o texto das linhas ficar alinhado com os títulos da página.

Layout

Resumo

Puxa o conteúdo 16px para fora dos lados, avançando sobre a margem ou o espaço interno de onde ele está. Serve para alinhar componentes que já têm 16px de espaço interno com o resto do conteúdo da tela. O caso mais comum é uma lista (RowList): o texto das linhas fica alinhado com os títulos da página, e o fundo de hover ou de toque de cada linha vai até a margem.

Comportamento no código (versão 18.0.0)

Tabelas de propriedades sem as props só técnicas. "Padrão" é o valor usado quando nada é informado.

PropValores aceitosPadrãoDescrição

¹ ℹ️ Lados: sem left e sem right, puxa dos dois lados. Com os dois juntos, também puxa dos dois lados.

⚠️ Valor fixo: o NegativeBox puxa sempre 16px, em qualquer tamanho de tela e em qualquer marca. Ele não acompanha a margem lateral do ResponsiveLayout, que pode ser maior no desktop. Use para compensar um espaço interno de 16px (como o das linhas de lista), não para levar o conteúdo até a borda da tela. Para chegar à borda, use o fullWidth do ResponsiveLayout, que tira as margens laterais.

ℹ️ Conteúdo cortado: se o espaço em volta corta o que passa da borda (ex.: dentro de um card ou de um painel com rolagem), os 16px puxados para fora ficam escondidos.

ℹ️ Sem identificação para testes: o NegativeBox não aceita dataAttributes.

ℹ️ Figma: o NegativeBox não existe no Figma. No design, o mesmo resultado é posicionar a lista para começar 16px antes da margem, de modo que o texto das linhas fique alinhado com o resto do conteúdo. No handoff, diga quando uma lista deve ficar alinhada assim.
