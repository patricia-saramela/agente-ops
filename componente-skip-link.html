Skip Link

O Skip Link é um link de acesso rápido para quem navega pelo teclado: fica escondido e aparece ao receber o foco com Tab. Use no topo das páginas para levar direto ao conteúdo principal (ex.: "Ir para o conteúdo principal"), sem passar por todo o menu.

Componentes

Resumo

Link de acesso rápido para quem navega pelo teclado: fica escondido e só aparece quando recebe o foco com a tecla Tab, no canto superior esquerdo. Ao ser ativado, leva direto a uma parte da página (ex.: "Ir para o conteúdo principal"), sem passar por todo o menu.

  • SkipLink: um link de acesso rápido.
  • SkipLinkNav: agrupa vários SkipLink numa lista de navegação, com um nome para o leitor de tela.

Regras que não aparecem no Figma (pontos de atenção no handoff)

SkipLink

  • ⚠️ Só aparece com o teclado: o Skip link não aparece para quem usa mouse ou toque. Desenhe-o numa tela separada ou numa anotação, mostrando o estado com foco.
  • ⚠️ Destino: informe para onde cada link leva (ex.: conteúdo principal, rodapé) e a ordem dos links.
  • ⚠️ Tamanho: o código usa o link no tamanho padrão, um pouco maior que o do Figma.
  • ⚠️ Dev Mode: o trecho de código usa sempre targetId="main-content". Só o texto segue o design.

ℹ️ Onde colocar: no começo da página, antes do cabeçalho, para ser o primeiro elemento alcançado com a tecla Tab.

ℹ️ Aparência: quando recebe o foco, o link aparece numa caixa com fundo de contêiner, borda, sombra e cantos arredondados, no canto superior esquerdo do elemento posicionado mais próximo (normalmente a página). Sem foco, fica escondido, mas o leitor de tela continua encontrando.

⚠️ Destino precisa ter o id: o elemento de destino precisa ter o mesmo id passado em targetId. Para o foco ir para ele (e não só a rolagem), use um elemento que receba foco ou adicione tabIndex={-1} a ele.

No Figma: propriedades e diferenças Desktop × Mobile

ℹ️ No Figma, o Skip link não tem propriedades: é a caixa com um Button Link dentro. O texto fica na camada do Button Link. Não há componente para o SkipLinkNav, que no código só agrupa os links numa lista, sem aparência própria.
