Resumo

Tabela de dados com cabeçalho e linhas, como a lista de faturas com data, valor e status. Pode ter ações por linha (ícones à direita), ficar dentro de uma caixa (boxed) e, no celular, rolar para o lado ou virar uma lista de cards.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Table

  • ⚠️ Fundo de marca: não use a Table com Theme context=Brand ou Negative esperando essas cores: no código, a tabela sempre tem as cores do fundo padrão.
  • ⚠️ Divisórias: no código, todas as linhas têm divisória, menos a última. Não desenhe linhas sem divisória no meio.
  • ⚠️ Celular: diga se a tabela rola para o lado ou se as linhas viram cards (collapse-rows). Nos cards, marque qual coluna é o título da linha (Header row).
  • ⚠️ Tabela vazia: desenhe o que aparece quando não há linhas (emptyCase).
  • ⚠️ Dev Mode: cada parte tem o próprio trecho de código, sempre com dados de exemplo. Na Table, só boxed (e, no Mobile, collapse-rows) seguem o design; na Table Row, o rowVerticalAlign; nas células, o texto e o columnTextAlign. Monte o heading e o content a partir do design.

⚠️ Título do card no collapse-rows: sem rowHeaderIndex, os cards não têm título: todas as células aparecem iguais, com o título da coluna antes. Defina rowHeaderIndex (normalmente 0).

ℹ️ Texto das células: um texto simples nas células aparece no tamanho padrão de tabela. Também dá para usar qualquer elemento (ex.: uma Tag de status).

Dúvidas reais respondidas pelo suporte

Dúvida: Dá para fazer conteúdo colapsado com "ver mais" (ex.: tabela técnica, conteúdo do fabricante)? Resposta: Existe o componente Table, mas ele não colapsa/expande. Alternativa: colocar a Table (ou o conteúdo) dentro do slot de um Accordion, ou usar um GroupedAccordion com AutoCollapsable/SingleOpen. Colapsar a Table seria uma melhoria a analisar.

Ref. #740 · 12/2025

Dúvida: Como usar a Table com muitas linhas? Há paginação? Resposta: Quando as linhas passam da altura definida, a Table ganha scroll. A Table está disponível no código. Para "carregar mais", é possível compor Table + Button Layout com Button Link (há exemplo no Playroom). Botão de outline com fundo transparente exigiria construção atômica ou evolução dos botões.
