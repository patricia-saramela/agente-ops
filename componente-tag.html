Tag

Componentes

Resumo

Etiqueta curta e colorida para destacar um status ou uma informação, como "Novo", "Paga" ou "Em aberto". Tem uma cor para cada tipo (type), pode ter um ícone à esquerda e um badge à direita, e tem uma versão menor (small). Não é clicável.

Regras que não aparecem no Figma (pontos de atenção no handoff)

Tag

  • ⚠️ Fundo negative: não use a Tag com Theme context=Negative esperando o fundo branco: no código, ela fica com as cores do fundo padrão.
  • ⚠️ Badge: diga se o badge é um ponto ou um número e, se for número, qual. Acima de 9, aparece "+9".
  • ⚠️ Cores próprias: se a tag tiver cores fora dos 7 tipos, informe as cores no handoff (backgroundColor e textColor).
  • ⚠️ Texto: a tag tem só texto, numa linha. Textos longos são cortados com reticências.
  • ⚠️ Dev Mode: o trecho de código segue o State, o Small, o Icon e o texto do design. O Badge sempre vira badge (o ponto), mesmo que o design mostre um número; o Theme context não aparece.

type'promo' | 'info' | 'active' | 'inactive' | 'success' | 'warning' | 'error''promo'🎨 Tipo da tag, que define as cores do texto e do fundo.¹
smallsim/nãofalse🎨 Versão menor: texto de 12px (em vez de 14px), menos espaço interno e altura mínima de 22px.

children (obrigatória)Texto da tag. Fica numa linha só: se não couber, é cortado com reticências. Com texto vazio, a tag não aparece.
IconÍcone de 16px à esquerda do texto (ex.: IconStarFilled), na mesma cor do texto.
badgeBadge à direita do texto: true mostra um ponto, e um número mostra o número (acima de 9, aparece "+9"). Com 0 ou false, não aparece.

¹ ℹ️ Cores por fundo: cada type tem um par de cores (texto e fundo) para o fundo padrão e outro para o fundo brand ou media. A troca é automática, conforme o fundo onde a tag está. No fundo negative, a tag usa as cores do fundo padrão. O backgroundColor e o textColor substituem essas cores em qualquer fundo, cada um só a sua parte: com só um deles, a outra cor continua vindo do type. O badge mantém a cor própria.

ℹ️ Tamanho: a tag tem a largura do texto, com no mínimo 56px (40px na small). O espaço interno diminui do lado em que há ícone ou badge.

⚠️ Só texto: o children aceita só texto. Para ícones, use o Icon; outros elementos dentro da tag dão erro de TypeScript.
