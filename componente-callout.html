Callout

O Callout é uma caixa de destaque com título, descrição e, se preciso, ícone, botões e botão de fechar. Use para avisos, dicas ou convites a uma ação dentro da página (ex.: "Ative a fatura digital"), sem interromper o fluxo do usuário como faria um modal.

Componentes

Resumo

Caixa de destaque que chama a atenção para uma informação importante ou uma sugestão dentro da página, sem interromper o fluxo do usuário. Tem título, descrição e, opcionalmente, um ícone ou imagem, botões de ação e um botão de fechar. Usado para avisos, dicas ou convites a uma ação (ex.: "Ative a fatura digital").

Regras que não aparecem no Figma (pontos de atenção no handoff)

Callout

  • ⚠️ Type do Figma: informe o ícone e a cor usados. No código eles são passados manualmente no asset, não por um tipo.
  • ⚠️ Fechar: no código, o callout não some sozinho ao clicar no ✕. Indique no fluxo o que acontece depois (ex.: o callout desaparece e não volta).
  • ⚠️ Dev Mode: o trecho de código que o Figma mostra no Dev Mode traduz o Theme context como variant, mas são coisas diferentes (o Theme context é o fundo da tela). Confira o variant pela propriedade Variant.
Combinações de propriedades: o que o código faz

Nenhuma combinação de variantes do Figma conflita com o código.

Dúvidas reais respondidas pelo suporte

Dúvida: Posso esticar o Callout (Fill container)? Qual Theme context usar sobre um fundo da mesma cor? Resposta: Pode ajustar a largura: os componentes são responsivos e não há regra de largura para o Callout (sugestão: ocupar a mesma largura da coluna de conteúdo, mas é livre). Para ter contraste num fundo igual ao do Callout, use Alternative. Os Theme contexts refletem as cores de fundo: Default = Background Container (branco); Inverse = Background Container Brand (cor da marca); Alternative = Background Container Alternative (cinza).

Ref. #199 · 03/2025

Dúvida: O Callout tem padding próprio em cima e embaixo, o que soma ao espaçamento até o botão. É bug? Resposta: O Callout tem padding externo pré-estabelecido (verificado: 24px). Considere isso ao calcular espaçamentos (ex.: para 40px até o botão, some 16px). Rows não têm esse padding externo no código. Problemas de implementação: canal de suporte de desenvolvimento.

Ref. #283 · 05/2025

Dúvida: O dev diz que não dá para pôr um Callout branco numa tela de fundo cinza. Resposta: Declare o variant Alternative no container (Responsive Layout): o Callout se ajusta sozinho para fundo branco.
