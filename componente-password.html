Password Field

Campos de formulário

Resumo

Campo para o usuário digitar uma senha. O texto aparece escondido (com pontos) e há um botão de olho à direita para mostrar ou esconder a senha. Por padrão, o navegador oferece a senha salva. Tem o mesmo visual do TextField e funciona sozinho ou dentro de um Form.

Regras que não aparecem no Figma (pontos de atenção no handoff)

PasswordField

  • ⚠️ Senha à mostra: o Figma não tem o estado com a senha visível. Se a tela precisar mostrar esse estado, desenhe à parte: texto visível e ícone de olho cortado (eye-off-regular).
  • ⚠️ Regras da senha: o código não confere nenhuma regra sozinho. Informe as regras (ex.: mínimo de 8 caracteres, letras e números) e as mensagens de erro. Se as regras aparecem embaixo do campo, use o Helper text.
  • ⚠️ Login ou senha nova: diga se o campo é de login (o navegador oferece a senha salva) ou de cadastro/troca de senha (o navegador sugere uma senha nova).
  • ⚠️ Dev Mode: o trecho de código segue o rótulo, o texto de ajuda, o Error, o Disabled e o Read only do design. O name é sempre "password-field".

Comportamento no código (versão 18.0.0)

Tabelas de propriedades sem as props só técnicas. "Padrão" é o valor usado quando nada é informado.

PasswordField

Quando usar
  • Use o PasswordField para senhas de login, criação ou troca de senha.
  • Use o PinField para códigos curtos digitados em caixinhas separadas (ex.: código recebido por SMS).

¹ ⚠️ Botão de olho com o campo desabilitado: com disabled, o campo fica esmaecido e não dá para digitar, mas o botão de olho continua funcionando: ainda dá para mostrar e esconder a senha.

ℹ️ Mostrar e esconder: a senha começa escondida. O botão de olho à direita alterna entre mostrar (ícone de olho cortado) e esconder (ícone de olho). Ao tocar nele, o foco volta para o campo, com o cursor no mesmo lugar. O ícone fica sempre lá e não pode ser trocado.

ℹ️ Leitor de tela: o botão de olho é lido como "mostrar senha" ou "esconder a senha" (o texto vem do tema e muda com o idioma).

ℹ️ Sem validação própria: o PasswordField não confere nenhuma regra de senha sozinho. Regras como tamanho mínimo ou caracteres obrigatórios ficam no validate.

ℹ️ Dois campos lado a lado: o PasswordField pode ser usado dentro de um DoubleField.

No Figma: propriedades e diferenças Desktop × Mobile

PasswordField

Figma: biblioteca Desktop › Password Field [D] · biblioteca Mobile › Password Field

ℹ️ No Figma, o Password Field tem o mesmo desenho do Text Field, com a senha escondida (pontos) e um botão de olho à direita. No código, o botão mostra e esconde a senha sozinho.
