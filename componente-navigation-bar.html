Navigation bar (Main, Funnel, Navigation Bar)

As barras de navegação ficam no topo da página. Use a Main Navigation Bar como navegação principal do site, com logo e seções; a Navigation Bar simples, com voltar e título, em telas internas; e a Funnel Navigation Bar, só com logo, em fluxos como compra ou cadastro, para o usuário não se distrair.

Parte 5 · Referência por componente

Cada página de componente tem: Resumo; Regras que não aparecem no Figma; Comportamento no código (o que acontece de fato na tela); No Figma (propriedades e diferenças Desktop × Mobile); e Dúvidas reais respondidas pelo suporte. Legenda: 🎨 muda o visual; ♿ acessibilidade; ⚠️ ponto de atenção; ℹ️ informação.

Componentes

Resumo

NavigationBar

Barra simples no topo da página, com botão de voltar, título e ações à direita. Use em telas internas, como o detalhe de um pedido. No Figma, é o Navigation Bar.

FunnelNavigationBar

Barra de navegação simplificada, no topo da página, só com o logo e ações à direita. Use em fluxos em que o usuário não deve se distrair com o resto do site, como uma compra ou um cadastro. No Figma, é o Funnel Navigation Bar.

MainNavigationBar

Barra de navegação principal do site, no topo da página: logo, seções do site e ações à direita (ex.: busca, conta). No desktop, as seções aparecem na barra e podem abrir menus; no celular e no tablet, ficam num menu hambúrguer. No Figma, é o Main Navigation Bar.

Regras que não aparecem no Figma (pontos de atenção no handoff)

FunnelNavigationBar

  • ⚠️ Dev Mode errado no Mobile: o Web/Funnel Navigation Bar está ligado ao código do NavigationBar, então o Dev Mode mostra <NavigationBar title="Title" />. O componente certo é o FunnelNavigationBar. No Desktop, o Funnel Navigation Bar não tem trecho de código.
  • ⚠️ Largura do conteúdo: no desktop, o código coloca o logo e as ações numa faixa central de 10 das 12 colunas, mais estreita que nas outras barras. Confira se o design segue essa largura.

MainNavigationBar

  • ⚠️ Sem ligação de código: o Dev Mode não mostra trecho de código para o Main Navigation Bar, nem no Desktop nem no Mobile.
  • ⚠️ Seções: informe quais seções têm menu, se o menu é por colunas (título + links) ou um conteúdo livre, e se a própria seção também leva a uma página.
  • ⚠️ Ícone nas abas: o código não aceita ícone nas seções. Evite usar o Icon da aba.
  • ⚠️ Celular com uma seção: no código, o menu hambúrguer não aparece com uma seção só.

NavigationBar

  • ⚠️ Dev Mode no Mobile: o Web/Navigation Bar não tem trecho de código, porque a ligação do Mobile aponta para o Web/Funnel Navigation Bar. No Desktop, o trecho mostra title, onBack e wide conforme o design, mas não as ações da direita.
  • ⚠️ Título longo: o código não quebra o título em duas linhas. Evite títulos longos.
  • ⚠️ Barra não fixa: se a barra não for fixa no topo, informe as margens laterais desejadas: o código tira as margens nesse caso.

Dúvidas reais respondidas pelo suporte

Dúvida: Há regra de quando exibir a Tab Bar no app (ex.: some a partir do 3º nível)? Resposta: A regra está no arquivo Master B2C, na página "Navegação e comportamentos" (Guias e Referências de uso).

Ref. #78 · 12/2024

Dúvida: No header do e-commerce, o Funnel Navigation desalinha logo e progress bar. Troco pelo Main Navigation? Resposta: Continue com o Funnel Navigation, que é o indicado para fluxos de funil. O desalinhamento foi reportado ao time global para correção, e a correção chega pela atualização.

Ref. #218 · 03/2025

Dúvida: No header (Android), o título grande fica cortado com reticências. Qual a aplicação correta? Resposta: No caso, era uma Nav Bar, não o componente Header. Consulte o guia de fundamentos (navegação e comportamentos, com diferenças entre Android e iOS) e os templates de Nav Bar da biblioteca Modules. A opção close da Nav Bar continua válida.

Ref. #252 · 04/2025

Dúvida: O Funnel Navigation Bar mobile não tem no Figma a propriedade para esconder os ícones da direita (que existe no código e no desktop). Resposta: Correção pedida ao time global. Enquanto isso, ajustar manualmente o alinhamento à esquerda é aceitável até a correção. Uso: o Funnel é para fluxos de transição/funil (ex.: web ou fluxo aberto a partir do app); num fluxo totalmente dentro do app, a Navigation Bar comum resolve.

Ref. #346 · 06/2025

Dúvida: No Main Navigation Bar em 1024px, as categorias não cabem. Vira menu hambúrguer? Resposta: No código, as palavras quebram de linha para caber. A recomendação é evitar títulos longos no menu. É possível forçar o menu hambúrguer em 1024px no código.

Ref. #774 · 01/2026

Dúvida: O Main Navigation em telas de 1920px fica com padding de 252px; precisamos de 120px. Resposta: Não ajuste manualmente: a correção vem com o novo breakpoint Extra Large Desktop no Responsive Layout (pedido ao time global), que deixará o padding correto.

Ref. #779 · 01/2026 · ⚠️ limitação atual

Dúvida: A Nav Bar customizada tem 20px de padding inferior. Pode, se sempre usamos múltiplos de 8? Resposta: O Design System não tem regra rígida de múltiplos de 4/8, embora os siga na maioria dos casos. Os 20px foram escolhidos pelo efeito de gradiente translúcido com blur e por casos extremos (ex.: título longo). No caso relatado, combinou-se 20px da nav até o primeiro item, totalizando 40px.

Ref. #1306 · 09/2026

Dúvida: Como fazer o header com seletor de perfil (segmented control) sem o componente pronto no Figma? Resposta: O componente entra pelo topSlot do Main Navigation Bar (já existe no código, ainda não no Figma). No Figma, crie um frame com 16px de padding lateral e coloque o componente nele. No handoff, oriente o dev a ativar o topSlot.
